# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

In this project, I analyzed customer shopping data to understand how customers purchase products, how much they spend, which categories they prefer, and how different factors are related to their shopping behavior.

I used **Python, SQL, Excel, and Power BI** for data cleaning, analysis, visualization, and dashboard creation.

The main purpose of this project was to turn customer shopping data into useful insights that can help understand customer preferences and purchasing patterns.

---

## 🎯 Business Problem

Customer shopping data contains a lot of useful information, but it needs to be analyzed properly to understand customer behavior.

Through this project, I looked at questions such as:

* Which categories are purchased the most?
* How much do customers spend?
* Which products are popular?
* Which payment methods do customers prefer?
* How do customer ratings vary?
* What is the purchasing behavior of subscribed and non-subscribed customers?
* How does discount usage relate to customer purchases?

## 📊 Dataset

The dataset contains customer shopping and transaction information.

Some of the important columns are:

| Column                 | Description                           |
| ---------------------- | ------------------------------------- |
| Customer ID            | Unique ID of the customer             |
| Age                    | Age of the customer                   |
| Gender                 | Gender of the customer                |
| Item Purchased         | Product purchased                     |
| Category               | Product category                      |
| Purchase Amount        | Amount spent on the purchase          |
| Review Rating          | Rating given by the customer          |
| Discount Applied       | Whether a discount was applied        |
| Previous Purchases     | Number of previous purchases          |
| Payment Method         | Payment method used                   |
| Shipping Type          | Shipping method selected              |
| Subscription Status    | Customer subscription status          |
| Frequency of Purchases | How frequently the customer purchases |
